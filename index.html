Kho AI

A — Gom thêm hoạt động mới

Hỏi AI khoảng 100 hoạt động khác ngoài list có sẵn (thể thao lạ, trải nghiệm, ăn uống, khám phá...). Hoạt động mới tự vào hòm 1, có nút gom địa điểm tự động bên dưới.

Chưa gom hoạt động. Cần API key ở mục B.

B — API key + gom địa điểm

Chưa gom. Lấy key miễn phí 2 phút tại aistudio.google.com/apikey
Mỗi lần gọi AI trả về khoảng 15-20 chỗ, web tự gọi nhiều lần cho tới khi đủ số lượng, bỏ trùng tên, tự lưu. Không có key vẫn mở hòm bình thường bằng list gợi ý sẵn.
